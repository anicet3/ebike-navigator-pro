# E-Bike Navigator Pro

Application Android de navigation pour vélo électrique. Profil initial Samebike 15 Ah, Samsung Galaxy S10+. Projet alpha, sans garantie de navigation. Aucune clé API dans le dépôt.

Le code Android et la compilation GitHub Actions sont en cours d'intégration. Utiliser une clé OpenRouteService personnelle dans les paramètres de l'application.
