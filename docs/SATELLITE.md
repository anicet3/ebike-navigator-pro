# Activation satellite

La version V0.3 accepte une URL HTTPS XYZ et une attribution dans Profil. Pour un usage personnel, MapTiler Cloud est un fournisseur possible sous réserve du plan, des quotas et des conditions d'attribution. Créer une clé cartographique dans https://cloud.maptiler.com/ puis consulter https://docs.maptiler.com/cloud/api/tiles/ et récupérer le modèle XYZ du tileset satellite (TileJSON). Remplacer la clé uniquement dans les paramètres locaux du téléphone. Ne jamais publier la clé dans GitHub. Conserver les crédits exacts du fournisseur, y compris les logos si requis. Le mode satellite reste désactivé tant que le fournisseur n'est pas configuré et testé. Aucune autorisation de téléchargement hors ligne n'est présumée.

Documentation : https://www.maptiler.com/cloud/pricing/ ; https://docs.maptiler.com/guides/developer/credentials/api-key/
